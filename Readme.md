## Версия 4.0 проекта для мотошколы

Предыдущие версии находятся в приватных репозиториях, так как содержат конфиденциальную информацию.

### Кратко о прошлых версиях
- **Первая версия:** Цель заключалась только в написании сервиса для подсчета зарплаты тренеров.
- **Вторая версия:** Было решено сделать платформу, на которой администраторы могли бы выполнять все свои задачи. **Именно эта версия в итоге осталась в эксплуатации.**
- **Третья версия:** Была инициирована мною для перехода на стек DRF + React.

### О четвертой версии
Четвертая версия - это моя личная инициатива. В ней я хочу реализовать собственное видение проекта, не будучи зависимым от требований заказчика.

**Ключевые особенности и цели:**
- **Качество кода:** Практика написания чистого, поддерживаемого и масштабируемого кода.
- **Тестирование:** Внедрение подхода Test-Driven Development (TDD) в отдельных частях проекта.
- **Стек:** Отказ от React. Считаю его избыточным для текущих задач. Сейчас я хочу сделать упор на изучение бэкенда, а не тратить время на освоение фреймворка и углубленное изучение JS.
- **Open Source:** В отличие от предыдущих версий, код четвертой версии наконец-то станет открытым.
